# Desafio Pilates — clone de interface

Reprodução front-end responsiva do quiz “Pilates na Parede”, feita em HTML, CSS e JavaScript puros.

## Executar

Abra `index.html` no navegador ou inicie um servidor local:

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Escopo

- Fluxo interativo com 8 etapas
- Layout responsivo para desktop e celular
- Ativos visuais locais
- Checkout externo integrado à PerfectPay
- Meta Pixel com eventos `PageView` e `InitiateCheckout`
- Sem coleta ou armazenamento das respostas do quiz
